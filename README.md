# 净化Tube（TubeFilter）

面向 **iOS 14.2** 的第三方 YouTube 前端，带一套完整的本地屏蔽系统。通过 **GitHub Actions 云编译**产出**未签名 IPA**，再由 **TrollStore（巨魔）** 安装。

不需要 Mac，不需要开发者账号，不需要越狱。

---

## 它是什么，不是什么

**是**：一个 SwiftUI 应用，用 WKWebView 承载 YouTube 页面，在渲染前后用原生 Swift 引擎决定哪些内容不该出现。

**不是**：官方 YouTube 应用，也不是对官方应用的注入改造。本仓库不包含任何 YouTube 的代码或素材。

这样设计的原因是务实的：YouTube 的公开数据接口在 2026 年已大面积依赖 `poToken` 与签名校验，独立客户端的数据层极不稳定；而网页本身永远可用。所以把「取内容」交给网页，把「筛内容」留在本机，两边都做自己最稳的事。

## 屏蔽系统

| 能力 | 实现方式 |
|---|---|
| 屏蔽词 | 纯文本 / 正则表达式，作用于标题、话题、频道名 |
| NLP 屏蔽词 | `NLEmbedding` 系统句向量 + 余弦相似度；系统模型不可用时自动降级为本地字符 n-gram 向量，功能不会失效 |
| 屏蔽用户 / 频道 | 按频道名或频道 ID 命中，含评论作者场景 |
| 屏蔽话题 | 按话题标签与元数据命中 |
| 屏蔽付费内容 | 识别会员专属 / Premium 徽章 |
| 质量过滤 | 标题党特征（诱导词、感叹号刷屏、全大写、百分比诱导）+ 时长下限 + 标题长度上限 |
| 反向屏蔽 | 直接移除播放页推荐墙与播放结束推荐，从结构上打断无限下滑 |
| 导出 / 导入 | 标准 JSON，含 schema 与版本号；导入兼容其他客户端导出的裸关键词列表 |
| 过滤统计 | 总体屏蔽率 + 按原因分布 + 规则热度排行 |
| 屏蔽历史 | 逐条记录命中原因与规则依据，支持按原因筛选 |

规则改动**即时生效**，不需要重新加载页面。点浏览页右上角的盾牌图标即可重扫当前页面。

## 信息流与推荐

- **四档模式**：`iOS 网页`（m.youtube.com）/ `Web 网页`（www.youtube.com）/ `本地流`（不加载远端推荐）/ `混合`（桌面版 + 本地引擎实时过滤）
- **登录态 / 非登录态切换**：非登录态使用 `nonPersistent` 数据存储，不写 Cookie、不落缓存，可随时对比两套推荐，直接对抗信息茧房
- **分区**：首页推荐 / 关注动态 / 热榜 / 搜索
- **搜索筛选**：排序、类型、上传时间、时长四个维度
- **搜索联想**：走 YouTube 搜索框背后的公开补全接口
- **本地流**：本机采集、去重、按最近出现排序，并标注来源页

关于搜索筛选的一个实现细节：`sp` 参数其实是 protobuf 的 base64 编码。手写常量只能一次启用一组筛选，本工程在 `SearchParamBuilder` 里直接编码 protobuf，因此四个维度可以任意叠加。

## 安装

### 1. 等 CI 出包

推送到 `main` 后，Actions 会自动构建。构建完成后进入本次运行的详情页，在底部 **Artifacts** 下载 `TubeFilter-unsigned-IPA`，解压得到 `TubeFilter-unsigned.ipa`。

### 2. 用巨魔安装

把 IPA 传到手机上，用 TrollStore 打开即可。TrollStore 会在安装时用自己的证书重新签名，所以**不需要**本仓库做任何签名配置。

本工程产物是纯 arm64、无签名二进制，适用于 TrollStore 支持的 iOS 14.0 beta 2 及以上版本。

### 3. 首次启动

内置了一组示例规则（含中英文标题党正则、语义参照词），开箱就能看到过滤效果。示例里默认关闭的条目是给你照格式填的模板。

## 本地构建（需要 Mac）

```bash
brew install xcodegen
xcodegen generate
open TubeFilter.xcodeproj
```

部署目标锁定 `iOS 14.0`，全程只使用 iOS 14 可用的 SwiftUI API（`NavigationView`、`LazyVStack`、`Picker`、`fileImporter` 等），没有使用 `NavigationStack`、`searchable`、`AsyncImage`、`refreshable` 这类 iOS 15+ 的新接口。

## 已知边界

- **播放器是网页的**，不是原生 AVPlayer。换来的是内容源永不枯竭。
- **不依赖 YouTube 账号 API**，所以没有订阅列表同步、没有观看记录回写。这是刻意的取舍：不碰账号体系就不会被账号体系反噬。
- **页面结构与选择器强耦合**。YouTube 改版后 `CORE/Web/InjectedScript.swift` 里的 `CARD_SELECTORS` / `TITLE_SELECTORS` 一类常量可能需要跟着调。
- **语义屏蔽的召回率取决于参照词的写法**。写「夸张标题诱导点击」这类描述性短语效果最好，写单个词效果差。
